# Priyansh Mathur

**Growth PM for regulated Indian fintech. I put products where the users already are.**

At Dezerv I took a wealth product to 20M reachable users by embedding it inside Moneycontrol, Livemint and Inshorts instead of buying downloads: 75% lower CAC than paid, organic sessions from 10K to 140K a month. Before that I grew Wint Wealth's organic traffic from 7K to 153K sessions a month.

On the side I ship AI products end to end, PRD first. Everything below is built and deployed by me.

## How I work

- Distribution is a product decision, not a marketing line item.
- Every build starts as a PRD: problem, user, metric, non-goals. Read one before the code.
- Regulated money means trust is the feature: compliance checks, honest numbers, a human in the loop where it matters.
